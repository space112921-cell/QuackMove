# QuackMove — Entrega 3 organizada

**Base:** rama `entrega-3` de `space112921-cell/QuackMove`.
La interfaz, textos, colores, funcionalidades y datos de demostración se conservan.
Cambios solicitados: paquete propio, identificadores Kotlin en inglés, carpetas por funciones,
ViewModels para estado y validación, repositorios para datos de ejemplo.

**Sin funcionalidades nuevas.** Sigue usando MapLibre y OpenFreeMap; no se incorporan Google APIs.
El registro continúa siendo de prueba y los cargadores siguen siendo ficticios.

Para abrir: Android Studio > File > Open > carpeta `QuackMove`.
Sincronizar Gradle y ejecutar el módulo `app` en el emulador.

Nota: el archivo binario `gradle-wrapper.jar` debe recuperarse del repositorio original
si se desea ejecutar `gradlew` directamente. Se incluye un instalador de un solo paso.
